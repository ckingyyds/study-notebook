### 3.Python语言的注释

- 用于解释程序的文字就是注释
- 被注释后的语句不会再被执行
- 注释提高了代码的可读性

**pthon注释的分类**

**1.单行注释**

单行注释通常使用 # 实现，当 # 出现在代码中时，从 # 开始，直到这一行的结尾，都不会被解析，不作为可执行内容

```python
# 这是Python的单行注释  
print("hello python")
```

**2.多行注释**

Python中没有专门的多行注释，多行注释使用一对三引号实现（"""或者'''）

```python
"""
1.这是Python的多行注释  python实际没有多行注释  
2.利用字符串表示形式作为多行注释  
3. 也可以使用三个单引号表示多行注释
"""

'''
   这是单引号的多行注释
'''
```

### Python算术运算符

| 运算符 | 描述 | 实例   a = 10  b = 20 |

### Python位运算符(神奇)

| 运算符 | 描述 | 实例 |
| --- | --- | --- |
| & 宏代换 | 按位与运算符：参与运算的两个值,如果两个相应位都为1,<br>则该位的结果为1,否则为0 | (a & b) 输出结果 12 ，二进制解释： 0000 1100 |
| \| | 按位或运算符：只要对应的二个二进位有一个为1时，<br>结果位就为1。 | (a \| b) 输出结果 61 ，二进制解释： 0011 1101 |
| ^ | 按位异或运算符：**相同为0 , 不用为1** | (a ^ b) 输出结果 49 ，二进制解释： 0011 0001 |
| ~ | 按位取反运算符：将二进制表示中的每一位取反，<br>0 变为 1，1 变为 0。<br>**~x**<br>类似于<br>**-x-1** | (~a ) 输出结果 -61 ，二进制解释： 1100 0011 (以补码形式表示)，在一个有符号二进制数的补码形式。 |

<<		  各二进制位全部左移指定位数，**高位丢弃，低位补 0**

<u>**>>		 **</u>** **各二进制位全部右移指定位数，**低位丢弃，高位补符号位**


##### 位运算符和逻辑运算符对比

- **位运算符（**`&`** / **`|`**）**：站在**二进制位**的角度，进行**数学计算**，返回**数字**。
- **逻辑运算符（**`and`** / **`or`**）**：站在**布尔真假**的角度，进行**逻辑判断**，返回**对象**（不一定是 True/False）。

#### Python 推导式

用一行代码实现遍历.循环才能实现的效果

- Python 推导式是一种独特的数据处理方式，可以从一个数据序列构建另一个新的数据序列的结构体。
- Python 推导式是一种强大且简洁的语法，适用于生成列表、字典、集合和生成器。
- 在使用推导式时，需要注意可读性，尽量保持表达式简洁，以免影响代码的可读性和可维护性。

Python 支持各种数据结构的推导式：

- 列表(list)推导式
- 字典(dict)推导式
- 集合(set)推导式
- 元组(tuple)推导式

##### 列表推导式

**用来快速创建列表,上来就写 for  in  ,有条件写条件,,最后在前面写生成表达式**

列表推导式格式为：

```python
[表达式 for 变量 in 列表] 

[out_exp_res for out_exp in input_list]



或者 



[表达式 for 变量 in 列表 if 条件]

[out_exp_res for out_exp in input_list if condition]
```

- out\_exp\_res：列表生成元素表达式，可以是有返回值的函数。
- for out\_exp in input\_list：迭代 input\_list 将 out\_exp 传入到 out\_exp\_res 表达式中。
- if condition：条件语句，可以过滤列表中不符合条件的值。

**过滤掉长度小于或等于3的字符串列表，并将剩下的转换成大写字母：**

```python

print(new_names)

['ALICE', 'JERRY', 'WENDY', 'SMITH']
```

### Lambda函数

Python 使用 **lambda** 来创建匿名函数。

**lambda 函数是一种小型、匿名的、内联函数**，它可以具有任意数量的参数，但只能有一个表达式。

匿名函数不需要使用 **def** 关键字定义完整函数。

lambda 函数通常用于编写简单的、单行的函数，通常在需要函数作为参数传递的情况下使用，例如在 map()、filter()、reduce() 等函数中。

#### lambda 函数特点

- lambda 函数是匿名的，它们没有函数名称，只能通过赋值给变量或作为参数传递给其他函数来使用。
- lambda 函数通常只包含一行代码，这使得它们适用于编写简单的函数。

#### lambda 语法格式

**lambda只是一个表达式,需要用变量接一下,才能输出**

```
lambda arguments: expression
```

- **lambda**是 Python 的关键字，用于定义 lambda 函数。
- arguments 是**参数**列表(形参)，可以包含零个或多个参数，但必须在冒号(:)前指定。
- expression 是一个**表达式**，用于计算并返回函数的结果。**相当于return值**
- 调用时要加括号传参

以下的 lambda 函数没有参数：

**实例**

```python
f = lambda: "Hello, world!"
print(f())  # 输出: Hello, world!
```

输出结果为：


###### 3.sum() —— 求和函数

【1. 函数语法】

sum(iterable, /, start=0)

【2. 函数功能】

从 start 开始，从**左到右对可迭代对象**（如列表、元组）中的元素进行累加，并返回总和。

【3. 函数解析】

- 参数 iterable：必需，一个可迭代对象，其元素通常是数值类型。
- 参数 start：可选，指定求和的初始值，默认为 0。
- 如果 iterable 为空，则返回 start 的值。
- 注意：该函数不能直接用于字符串拼接（请使用 ''.join()）。
- 该函数在数值统计、数据汇总中极为常用。

【4. 案例代码】

```python
示例 1：基本列表求和
numbers = [1, 2, 3, 4, 5]
print(sum(numbers))          # 输出: 15
示例 2：指定起始值
print(sum(numbers, 10))      # 输出: 25 (15 + 10)
示例 3：空列表求和
empty_list = []
print(sum(empty_list))       # 输出: 0
print(sum(empty_list, 100))  # 输出: 100
示例 4：处理浮点数
prices = [19.99, 5.49, 3.75]
print(sum(prices))           # 输出: 29.23
```

###### 4.min() —— 最小值函数

【1. 函数语法】

min(iterable, \*[, key, default])  或  min(arg1, arg2, \*args[, key])

【2. 函数功能】

返回可迭代对象中的最小值，或返回多个参数中的最小值。

【3. 函数解析】

- 可以接受一个可迭代对象，或者直接接受多个参数。
- 参数 key：可选，指定一个函数，用于从每个元素中提取比较键（类似排序规则）。
- 参数 default：可选，当可迭代对象为空时返回的默认值（Python 3.4+）。
- 比较基于 '<' 操作符，因此元素必须支持比较运算。
- 如果同时存在多个最小值，则返回第一个遇到的。

**【4. 案例代码】**

```python
示例 1：基本用法（列表）
numbers = [7, 2, 9, 1, 5]
print(min(numbers))          # 输出: 1
示例 2：多个参数
print(min(10, 3, 8, 2))      # 输出: 2
示例 3：使用 key 参数（用字符串长度比较）
words = ["apple", "banana", "pear", "kiwi"]
print(min(words, key=len))   # 输出: "pear" (长度为4，与kiwi同为4，但pear先出现)
示例 4：使用 key 参数（用字典值比较）
students = [{"name": "Alice", "score": 88}, {"name": "Bob", "score": 75}]
lowest = min(students, key=lambda s: s["score"])
print(lowest)                # 输出: {'name': 'Bob', 'score': 75}
```

max(iterable, \*[, key, default])  或  max(arg1, arg2, \*args[, key])

返回可迭代对象中的最大值，或返回多个参数中的最大值。

【3. 函数解析】

```python
scores = [85, 92, 78, 96, 88]

nums = [-10, 5, 8, -3]
```

###### 6. zip() —— 打包函数

【1. 函数语法】

zip(\*iterables, strict=False)

【2. 函数功能】

**将多个可迭代对象中对应位置的元素打包成一个个元组**，然后返回由这些**由元组组成的迭代器**。

如果传入的可迭代对象长度不同，则结果长度与最短的可迭代对象一致,就是以小为主,匹配完结束（**除非 strict=True** ,这样不一致时会报错）。

【3. 函数解析】

- 参数 \*iterables：任意数量的可迭代对象（列表、元组、字符串等）。
- 参数 strict：Python 3.10+ 引入，若设为 True，当可迭代对象长度不一致时引发 ValueError。
- 返回一个迭代器，因此需要用 list() 或 for 循环来查看内容。
- **常用于并行遍历多个序列，或者将两个列表组合成字典**。

【4. 案例代码】

```python
#示例 1：基本打包
names = ["Alice", "Bob", "Charlie"]
scores = [85, 92, 78]
zipped = zip(names, scores)  #zip的属性要和调用的迭代对象名一致
print(list(zipped))  # 输出: [('Alice', 85), ('Bob', 92), ('Charlie', 78)]
#迭代器一次性消费：重要！zip() 返回的迭代器只能被遍历一次。
#第一次 list(zipped) 已经把数据消费完了
#第二次 list(zipped) 得到的是空列表
#所以 for 循环不会输出任何内容
for i in list(zipped):
    print(i)

#示例 2：长度不同时（默认截断）
a = [1, 2, 3]
b = ['a', 'b']
print(list(zip(a, b)))  # 输出: [(1, 'a'), (2, 'b')]  # 3被忽略

#示例 3：使用 strict=True (Python 3.10+)
try:
list(zip(a, b, strict=True))  # 会引发 ValueError
except ValueError as e:
print(e)  # 输出: zip() argument 2 is shorter than argument 1

#示例 4：解压（使用 * 操作符和 zip）
pairs = [('Alice', 85), ('Bob', 92), ('Charlie', 78)]
names, scores = zip(*pairs)  #我勒个解压
print(names)   # 输出: ('Alice', 'Bob', 'Charlie')
print(scores)  # 输出: (85, 92, 78)

#示例 5：构建字典
keys = ['name', 'age', 'city']
values = ['Alice', 25, 'New York']
dictionary = dict(zip(keys, values))
print(dictionary)  
# 输出: {'name': 'Alice', 'age': 25, 'city': 'New York'}
```

###### 7. map() —— 映射函数

【1. 函数语法】

map(function, iterable, \*iterables)

【2. 函数功能】

对可迭代对象中的每个元素应用指定的函数，并返回一个包含所有结果的迭代器。

【3. 函数解析】

- 参数 function：一个函数对象，可以接收一个或多个参数。也就是**对迭代对象进行处理**
- 参数 iterable：一个或多个**可迭代对象**。
- 如果传入多个可迭代对象，则 function 必须接收相应数量的参数，且迭代在最短的可迭代对象耗尽时停止。
- 返回一个 map 对象（迭代器），具有惰性求值的特点。
- 常用于批量处理数据，**替代显式的 for 循环,用for循环也能实现**。

【4. 案例代码】

```python
示例 1：对列表元素求平方
def square(x):
return x ** 2
numbers = [1, 2, 3, 4, 5]
result = map(square, numbers)
print(list(result))        # 输出: [1, 4, 9, 16, 25]

示例 2：使用 lambda 表达式
result = map(lambda x: x * 2, [1, 2, 3])
print(list(result))        # 输出: [2, 4, 6]

示例 3：多个可迭代对象（对应元素相加）
a = [1, 2, 3]
b = [10, 20, 30]
result = map(lambda x, y: x + y, a, b)
print(list(result))        # 输出: [11, 22, 33]

示例 4：处理字符串列表（转换为首字母大写）
names = ["alice", "bob", "charlie"]
result = map(str.capitalize, names)
print(list(result))        # 输出: ['Alice', 'Bob', 'Charlie']

示例 5：与其他函数结合（类型转换）
str_nums = ["1", "2", "3", "4"]
int_nums = list(map(int, str_nums))
print(int_nums)            # 输出: [1, 2, 3, 4]
```

###### 8. reduce() —— 归约函数（需从 functools 导入）

【1. 函数语法】

from functools import reduce

reduce(function, iterable[, initializer])

【2. 函数功能】

对可迭代对象中的元素，累积地应用一个具有两个参数的函数，***将序列归约为单个值***。

【3. 函数解析】

- 参数 function：接收两个参数的函数。**对迭代对象进行处理**
- 参数 iterable：可迭代对象。
- 参数 initializer：可选，初始值。如果提供，则放在序列之前进行计算。
- 工作原理：***先取前两个元素应用 function，得到结果后再与第三个元素应用 function***，以此类推。
- 如果没有 initializer 且 iterable 只有一个元素，则返回该元素；若 iterable 为空，则必须提供 initializer，否则抛出 TypeError。
- Python 3 中，reduce 被移出内置命名空间，需要显式导入。

【4. 案例代码】

```python
from functools 
import reduce
示例 1：计算列表所有元素的乘积
numbers = [1, 2, 3, 4, 5]
product = reduce(lambda x, y: x * y, numbers)
print(product)              # 输出: 120 (12345)

示例 2：使用 initializer 初始值
product_with_init = reduce(lambda x, y: x * y, numbers, 10)
print(product_with_init)    # 输出: 1200 (10*1234*5)

示例 3：连接字符串列表
words = ["Hello", " ", "World", "!"]
sentence = reduce(lambda x, y: x + y, words)
print(sentence)             # 输出: "Hello World!"

示例 4：找出列表中的最大值（不用 max 函数）
max_val = reduce(lambda x, y: x if x > y else y, [7, 12, 5, 9])
print(max_val)              # 输出: 12

示例 5：复杂应用——统计字符出现次数（无需 Counter）
text = "abracadabra"
char_counts = reduce(lambda acc, c: {**acc, c: acc.get(c, 0) + 1}, text, {})
print(char_counts)          # 输出: {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}
```

###### 9.Python 拆包（Unpacking）

###### 1.拆包基础 —— 基本解构赋值

================================================================================

【1. 语法】

变量1, 变量2, ... = 可迭代对象

【2. 功能】

将可迭代对象（如列表、元组、字符串）中的元素按顺序一一赋值给左侧的变量。

【3. 解析】

- 左侧变量数量必须与右侧可迭代对象元素数量严格相等（除非使用 \* 号）。\*号:不定长度
- 这是最基础的拆包形式，常用于交换变量值。
- 任何可迭代对象都可以被拆包。

【4. 案例代码】

```python
示例 1：元组拆包
point = (10, 20)
x, y = point
print(x, y)          # 输出: 10 20
示例 2：列表拆包
rgb = [255, 128, 0]
red, green, blue = rgb
print(red, blue)     # 输出: 255 0

示例 3：字符串拆包
a, b, c = "XYZ"
print(a, b, c)       # 输出: X Y Z

m, n = 5, 10m, n = n, mprint(m, n)          # 输出: 10 5
```

###### 2. 进阶拆包 —— * 号打包（任意长度）

【1. 语法】

变量1, \*中间变量, 变量N = 可迭代对象

【2. 功能】

使用 \* 号将多余的元素收集为一个列表，赋值给带 \* 的变量。

【3. 解析】

- \* 号可以出现在左侧任意位置（开头、中间、结尾）。
- \*号可以出现在左侧任意位置（开头、中间、结尾）。
- 带 \* 的变量始终接收一个列表，即使没有匹配到元素，也会得到空列表。
- 极大简化了处理不定长序列的代码。

【4. 案例代码】

```python
示例 1：* 在末尾（收集剩余所有元素）
first, *rest = [1, 2, 3, 4, 5]
print(first)         # 输出: 1
print(rest)          # 输出: [2, 3, 4, 5]
示例 2：* 在中间
first, *middle, last = [10, 20, 30, 40, 50]
print(first)         # 输出: 10
print(middle)        # 输出: [20, 30, 40]
print(last)          # 输出: 50
# 示例 2_1: 有*号的列表拆包
rgb = [255, 128, 0, 60, 21, 78]
red, *reds, blue = rgb
print(red, blue, reds)    # 输出: 255 78 [128, 0, 60, 21]
示例 3：* 在开头
*head, last_two = [100, 200, 300, 400]
print(head)          # 输出: [100, 200, 300]
print(last_two)      # 输出: 400
示例 4：空匹配情况（* 得到空列表）
first, *rest = [1]
print(rest)          # 输出: []
```

###### 3. 深度拆包 —— 嵌套结构拆包

【1. 语法】

(变量1, (变量2, 变量3)) = (值1, (值2, 值3))

【2. 功能】

对嵌套的可迭代对象进行匹配拆包，结构必须一致。

【3. 解析】

- 拆包时左侧的括号结构必须与右侧数据层级一致。
- 常用于解析嵌套的 JSON 或元组数据。
- 同样支持在嵌套结构中使用 \* 号。

【4. 案例代码】

```python
示例 1：嵌套元组拆包

for key, value in records:   # 循环时直接拆包

输出:
A 1
B 2
示例 3：复杂嵌套带 * 号
nested = [1, (2, 3, 4), 5]
a, (b, *rest), c = nested

```

###### 4. 函数调用中的拆包 —— * 和 ** 的妙用

【1. 语法】

func(\*列表/元组)        # 将序列元素拆解为位置参数

func(\*\*字典)            # 将字典拆解为关键字参数

【2. 功能】

在调用函数时，将可迭代对象或字典拆解为单独的参数传递给函数。

【3. 解析】

- \*用于位置参数，\*\* 用于关键字参数（字典的键必须与参数名匹配）。
- 极大提升了代码的灵活性和可读性。
- 常与 zip、map 等高阶函数结合使用。

【4. 案例代码】

```python
示例 1：* 拆解列表作为位置参数
def add(a, b, c):
return a + b + c
numbers = [1, 2, 3]
print(add(*numbers))        # 输出: 6 (等同于 add(1,2,3))
示例 2：** 拆解字典作为关键字参数
def introduce(name, age):
return f"{name} is {age} years old."
person = {"name": "Bob", "age": 25}
print(introduce(**person))  # 输出: Bob is 25 years old.
示例 3：结合 zip 和 map（将二维列表拆成行和列）
matrix = [[1, 2], [3, 4], [5, 6]]
使用 * 拆解 matrix 为三个元素（每行一个列表），zip 将其打包成列
columns = list(zip(*matrix))
print(columns)              # 输出: [(1, 3, 5), (2, 4, 6)]
示例 4：map 函数与拆包（处理成对数据）
pairs = [(1, 3), (2, 4), (5, 7)]
用 * 拆包每一对，传递给 lambda
result = list(map(lambda x, y: x + y, *zip(*pairs)))  # 不推荐这么复杂，仅供演示
更易读的方式：
result = [x + y for x, y in pairs]  # 列表推导式更清晰
print(result)           # 输出: [4, 6, 12]
示例 5：使用 * 合并多个列表（模拟 zip 的反向操作）
a = [1, 2]
b = [3, 4]
merged = list(zip(a, b))   # 压缩
```

### 递归

自己调用自己

含义：如果一个函数在内部不调用其他的函数，而是调用它本身的话，这个函数就是递归函数。

条件:

1.**明确的结束条件**

2.每进行更深一层的递归时，问题规模相比上次递归都要有所减少。可以在return处写调用递归

3.相邻两次重复之间有紧密的联系。

代码:

```python
#案例一:
#累计1-100的和
#方法一:循环
def add(n):
    v_sum = 0
    for i in range(n+1):
        v_sum += i
    return v_sum
print(add(100))

#方法二:递归
def add2(n):
    if n == 1:#明确的结束条件
        return 1   
    else:
        return n+add2(n-1)  #问题规模相比上次递归都要有所减少。
print(add2(100))
#相当于return了:100+add2(99)→100+99+add2(98)..+add2(2)+1 → 5050

#案例二:
##斐波那契数列：
# 1,1, 2, 3, 5, 8, 13..
#规律：从第三项开始，每一项都等于前两项之和，即n=(n-2)+(n-1）
#n--当前项，n-1-—前一项n-2-—前前一项
def funa(n):    #n代表第n项
    if n <= 1:
        return n
    else:
        return funa (n-2)+funa (n-1)
print (funa(5))
```

## 第8章 模块和包

### 模块

用 python 解释器来编程，从 Python 解释器退出再进入，那么你定义的所有的方法和变量就都消失了。为此 Python 提供了一个办法，把这些定义的变量，函数存放在文件中，为一些脚本或者交互式的解释器实例使用，这个文件被称为模块。

模块是一个包含所有你定义的函数和变量的文件，其后缀名是.py。模块可以被别的程序引入，以使用该模块中的函数等功能。这也是使用 python 标准库的方法

#### import 语句

想使用 Python 源文件，只需在另一个源文件里执行 import 语句，语法如下：

```
import module1[, module2[,... moduleN]
```

当解释器遇到 import 语句，如果模块在当前的搜索路径就会被导入，一个模块只会被导入一次，不管你执行了多少次 **import**。这样可以防止导入模块被一遍又一遍地执行

#### from … import 语句

Python 的 from 语句让你从模块中导入一个指定的部分到当前命名空间中，语法如下：

```
from modname import name1[, name2[, ... nameN]]
```

#### from … import * 语句

把一个模块的所有内容全都导入到当前的命名空间也是可行的，只需使用如下声明：

```
from modname import *
```

这提供了一个简单的方法来导入一个模块中的所有项目。然而这种声明不该被过多地使用

#### __name__属性

一个模块被另一个程序第一次引入时，其主程序将运行。如果我们想在模块被引入时，模块中的某一程序块不执行，我们可以用\_\_name\_\_属性来使该程序块仅在该模块自身运行时执行

```python
if __name__ == '__main__':
   print('程序自身在运行')
else:
   print('我来自另一模块')
```

**说明：** 每个模块都有一个\_\_name\_\_属性，当其值是'\_\_main\_\_'时，表明该模块自身在运行，否则是被引入。

**说明：\_\_name\_\_** 与 **\_\_main\_\_** 底下是双下划线， **\_ \_** 是这样去掉中间的那个空格

如何引入不同目录中的模块

```python
'''
 场景： 目录dir2中的模块 引入 dir1中的模块
 错误：ModuleNotFoundError: No module named 'customer_utile'
 原因： 模块所在的目录,不在python解释器寻找模块的范围内
 解决方案： 
      1. 将对应的目录添加到python解释器寻找模块的范围内
      2. 将目录改为包的形式 将包直接创建在项目的根路径下  package 推荐  
'''
import os
import sys

#  获取当前文件所在的目录
current_dir = os.path.dirname(os.path.abspath(__file__))
#  添加 dir1 到 python解释器查询的路径列表中
mode_dir = os.path.join(current_dir, '..\\dir1')
sys.path.append(mode_dir)

import customer_utile

result = customer_utile.fn_add(1, 2)
print(result)
```

### 包

包是一种管理 Python 模块命名空间的形式，采用"点模块名称"。比如一个模块的名称是 A.B， 那么他表示一个包 A中的子模块 B 。就好像使用模块的时候，你不用担心不同模块之间的全局变量相互影响一样，采用点模块名称这种形式也不用担心不同库之间的模块重名的情况。这样不同的作者都可以提供 NumPy 模块，或者是 Python 图形库。

```python
import pack01.user as usr
# usr.fn1()
# usr.fn2()

# from pack01.user import *
# fn1()
# fn2()
```

```python
# 通过as 关键词  给导入的函数起别名 用于区分不同模块中相同名字的函数
from pack01.user import fn1 as fn1_pack1
from pack02.user import fn1 as fn1_pack2

fn1_pack1()
fn1_pack2()
```
