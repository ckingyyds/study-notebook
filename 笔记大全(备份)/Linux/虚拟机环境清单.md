## 一、一句话总览

**一套 Docker 里跑了 5 个容器（4 个是课程实验，1 个是早就有的 MySQL），对外开了 6 个业务端口；宿主机上另外还装着一套 Tomcat 和一个 Redis。**

分三层看：

```text
宿主机 CentOS
├── 系统自己的服务      sshd(22) / postfix(25) / cupsd(631) / rpcbind(111) / dnsmasq(53)
├── 宿主机上手动装的     Tomcat 8080（/opt/tomcat8）+ Redis 6379（只监听本机）
└── Docker
    ├── nginx01   :80    ← 统一入口，反向代理 + 负载均衡
    ├── tomcat01  :8081  ┐
    ├── tomcat02  :8082  ├ 三个后端，都在 tomcat_net 网络里
    ├── tomcat03  :8083  ┘
    └── mysql     :3306  ← 早就有的，挂在默认 bridge 网络
```

## 二、端口地图：每个端口背后是谁

| 端口 | 监听进程 | 它是什么 | 对外可访问 |
| :--- | :--- | :--- | :--- |
| **22** | `sshd` | 远程登录（FinalShell / Xshell 连的就是它） | 是 |
| **80** | `docker-proxy` | **nginx01**，统一入口 | 是 |
| **8080** | `java`（pid 41756） | **宿主机 Tomcat**，`/opt/tomcat8` | 是 |
| **8081** | `docker-proxy` | **tomcat01** 容器 | 是 |
| **8082** | `docker-proxy` | **tomcat02** 容器 | 是 |
| **8083** | `docker-proxy` | **tomcat03** 容器 | 是 |
| **3306** | `docker-proxy` | **mysql** 容器 | 是 |
| 6379 | `redis-server` | 宿主机装的 Redis，**只监听 127.0.0.1** | 否（本机才连得上） |
| 8005 | `java` | Tomcat 的 **shutdown 端口**，用来接收关闭指令 | 否（127.0.0.1） |
| 111 | `rpcbind` | NFS 相关，CentOS 自带 | 是（但不影响） |
| 25 | `master` | postfix 邮件服务，系统自带 | 否（127.0.0.1） |
| 631 | `cupsd` | 打印服务，系统自带 | 否（127.0.0.1） |
| 53 | `dnsmasq` | libvirt（虚拟机管理器）的 DNS，挂在 192.168.122.1 | 否 |

> **判断端口被谁占了，看 `sudo ss -lntp` 最后一列**：
> `docker-proxy` = 某个容器的端口映射；`java` = 宿主机 Tomcat；其他名字都是系统服务。

## 三、容器 ↔ 端口 ↔ 挂载目录

| 容器名 | 镜像 | 宿主机端口 | 挂载 | 作用 |
| :--- | :--- | :--- | :--- | :--- |
| `nginx01` | nginx:latest | **80** | `default.conf` + `/home/zyc/web` | 统一入口、反向代理、负载均衡 |
| `tomcat01` | tomcat:8 | **8081** | `/home/zyc/web1` → `webapps` | 后端 1 |
| `tomcat02` | tomcat:8 | **8082** | `/home/zyc/web2` → `webapps` | 后端 2 |
| `tomcat03` | tomcat:8 | **8083** | `/home/zyc/web3` → `webapps` | 后端 3 |
| `mysql` | mysql:8.0 | **3306** | `/data/mysql` → `/var/lib/mysql` | 数据库（早就有的） |

**挂载的意思**：容器删了，这些目录里的东西还在；往目录里改文件，容器里立刻生效，不用重启。

三台 Tomcat 挂的是**不同目录**（`web1/web2/web3`），所以我能在同一个页面上看到三台不同的标记。

## 七、常用速查

```bash
# 现在有什么容器、开在哪
docker ps
docker ps -a                      # 连已停的也列出来

# 端口是谁占的（要 sudo 才看得到进程名）
sudo ss -lntp | grep -E ':80 |:8080|:8081'

# 容器挂了什么目录
docker inspect nginx01 --format '{{range .Mounts}}{{.Source}} -> {{.Destination}}{{println}}{{end}}'

# 把整个家底重新存一份
docker ps -a; docker images; docker network ls; docker system df

# 清掉没用的镜像和缓存
docker system df
docker rmi tomcat-cart:v1
```

## 八、以后每加一样东西，往这张表里补一行

加完就更新，比事后回忆省事得多。判断一个东西该不该留，问三个问题：

1. **它占着端口吗？** 占了就要记下来，否则以后端口冲突查不到原因。
2. **它挂了宿主机哪个目录？** 那个目录删了，容器里就空了。
3. **删了会不会丢数据？** 挂载的数据卷（比如 `/data/mysql`）删了就真没了。
