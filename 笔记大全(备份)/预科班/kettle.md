#### 插入/更新(输出)

有则改之,无则加之

create table emp1 as select * from emp where deptno in (10,20);
create table emp2 as select * from emp where deptno in (30,20);
update emp2 set ename = lower(ename),sal=sal+10000 where deptno =20

oracle的scott中的emp表

很简单理解,你有一张表1里面有很多数据,另一张表2有相同的字段和一些数据,两个表的数据中,有一些数据是部分字段列的数据相同,也有其他是完全不同的数据

现在要把表2插入表1,相同字段列(主键相同)的数据更新成表2(有则改之),完全不同的数据插入表1(无则加之)
